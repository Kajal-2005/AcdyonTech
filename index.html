Setup

Three steps, then you're done.

1

Create a project

Give it a name and a colour. Connect your GitHub repo if you want auto-drafts from pull request titles.

2

Write your first entry

Tag it New, Improved, or Fix. Write one sentence about what changed. Publish or schedule it.

3

Paste one script tag

Drop it in your app or share the public URL. Your users can now see exactly what you shipped.
